# Development Tools & Execution Environment

This document specifies the package managers, runtimes, and libraries required to build, test, and run the project using modern developer workflows.

---

## 1. Environment Requirements & Package Managers
- **Node.js & npm:** For scaffolding and running the frontend client (`npm install`, `npm run dev`).
- **Python & uv / pip:** For managing backend virtual environments and running FastAPI (`uv venv`, `uv pip install`, `uvicorn`).
